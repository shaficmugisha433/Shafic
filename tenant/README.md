# Tenant Portal

This folder contains a separate tenant-facing portal for RentManager.

## Features

- Tenant dashboard with lease and rent information
- Payment options for MTN Mobile Money, Airtel Money, bank transfer, and office payment
- Room availability search and tenant room request submission
- Separate complaint and message channel for resident communication
- Local browser storage for submitted requests
- Responsive tenant-only navigation with no admin record controls

## Run

Open `index.html` in a browser, or serve the folder from a local web server.

> The tenant portal is intentionally separate from the admin pages in the root project folder.
